# devboy-slack

[![Crates.io](https://img.shields.io/crates/v/devboy-slack.svg)](https://crates.io/crates/devboy-slack)
[![Docs.rs](https://docs.rs/devboy-slack/badge.svg)](https://docs.rs/devboy-slack)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Slack provider for [`devboy-tools`](https://github.com/meteora-pro/devboy-tools). Implements `MessengerProvider` and `Provider` from [`devboy-core`](https://crates.io/crates/devboy-core) against the Slack Web API.

## Add to your project

```toml
[dependencies]
devboy-core = "0.26"
devboy-slack = "0.26"
```

## Documentation

API reference on [docs.rs/devboy-slack](https://docs.rs/devboy-slack).

For the full bundle (CLI, MCP server, agent skills) see the [main project README](https://github.com/meteora-pro/devboy-tools#readme).
