# devboy-clickup

[![Crates.io](https://img.shields.io/crates/v/devboy-clickup.svg)](https://crates.io/crates/devboy-clickup)
[![Docs.rs](https://docs.rs/devboy-clickup/badge.svg)](https://docs.rs/devboy-clickup)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

ClickUp provider for [`devboy-tools`](https://github.com/meteora-pro/devboy-tools). Implements `IssueProvider` and `Provider` from [`devboy-core`](https://crates.io/crates/devboy-core) against the ClickUp REST API.

## Add to your project

```toml
[dependencies]
devboy-core = "0.26"
devboy-clickup = "0.26"
```

## Documentation

API reference on [docs.rs/devboy-clickup](https://docs.rs/devboy-clickup).

For the full bundle (CLI, MCP server, agent skills) see the [main project README](https://github.com/meteora-pro/devboy-tools#readme).
