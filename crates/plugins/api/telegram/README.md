# devboy-telegram

[![Crates.io](https://img.shields.io/crates/v/devboy-telegram.svg)](https://crates.io/crates/devboy-telegram)
[![Docs.rs](https://docs.rs/devboy-telegram/badge.svg)](https://docs.rs/devboy-telegram)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

Telegram provider for [`devboy-tools`](https://github.com/meteora-pro/devboy-tools). Implements `MessengerProvider` and `Provider` from [`devboy-core`](https://crates.io/crates/devboy-core) against the Telegram Bot API.

## Add to your project

```toml
[dependencies]
devboy-core = "0.30"
devboy-telegram = "0.30"
```

## Documentation

API reference on [docs.rs/devboy-telegram](https://docs.rs/devboy-telegram).
